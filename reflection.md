# Mission Reflection

## 1. Which cloud infrastructure component is most important? Why?

I think compute is one of the most important cloud infrastructure components because it runs applications and processes tasks. Without compute resources, cloud applications and services cannot operate. However, compute also depends on storage, networking, and the operating system to work properly.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and reliable operating system for cloud servers. It is widely used because it is flexible and provides many command-line tools for managing and monitoring resources. In this laboratory, I used Linux commands to investigate the server's CPU, memory, storage, operating system, and network information.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the resources, configurations, and decisions made before deployment. It gives engineers a clear reference when troubleshooting problems or maintaining the infrastructure. Good documentation also makes it easier for other team members to understand how the system is designed.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free -h`, `lsblk`, `df -h`, `hostname`, and `hostname -I`. I also learned how to organize technical information using Markdown and manage files in a GitHub repository. Creating the cloud architecture diagram helped me understand how different infrastructure components connect.

My GitHub portfolio has improved because it now contains organized documentation about Linux infrastructure, cloud components, and cloud provider services. I also added screenshots and a cloud architecture diagram as evidence of my work. This laboratory helped me practice technical documentation, GitHub file management, Linux investigation, and basic cloud infrastructure planning. Overall, the activity gave me a better understanding of how cloud infrastructure components work together.
