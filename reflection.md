# Mission Reflection

## 1. Which cloud infrastructure component is most important? Why?
I think compute is one of the most important components because it runs applications and processes tasks. Without compute resources, cloud applications cannot operate.

## 2. How does Linux support cloud computing?
Linux provides a stable operating system for cloud servers. Its command-line tools also help cloud engineers manage and monitor resources.

## 3. Why is technical documentation important?
Technical documentation records the resources, configurations, and decisions made before deployment. It also helps with troubleshooting and future maintenance.

## 4. What new skills did you learn?
I learned how to investigate a Linux server using commands such as lscpu, free, lsblk, and df. I also learned how to document cloud infrastructure using Markdown and GitHub.

## 5. How has your GitHub portfolio improved?
My portfolio is now more organized because it contains documentation about Linux infrastructure, cloud components, and cloud provider services. It shows my progress in learning cloud computing.
