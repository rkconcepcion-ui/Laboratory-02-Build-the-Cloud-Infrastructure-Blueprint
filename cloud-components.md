# Cloud Infrastructure Components

## Compute Resources
The KillerCoda server uses an Intel Xeon CPU with 1 core. Compute resources process applications and workloads and are essential for running cloud services.

## Storage Resources
The server has a 20 GiB disk. Storage keeps the operating system, applications, files, and other data.

## Networking Resources
The server has IP addresses 172.30.2.1 and 172.17.0.1. Networking allows systems and services to communicate with each other.

## Operating System
The server runs Ubuntu Linux with kernel 6.8.0-138-generic. The operating system manages hardware and provides an environment for applications.

## Relationship
Compute processes data, storage keeps data, networking provides communication, and the operating system manages the resources. Together, these components form the basic infrastructure needed to run cloud workloads.
