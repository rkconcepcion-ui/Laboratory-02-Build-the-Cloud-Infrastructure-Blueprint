# Laboratory 02 - Build the Cloud Infrastructure Blueprint

## Mission Overview
This laboratory investigates cloud infrastructure using a Linux server in the KillerCoda Playground.

## Objectives
- Investigate Linux server resources.
- Identify compute, storage, networking, and operating system components.
- Compare AWS, Azure, and Google Cloud.
- Document findings using Markdown.
- Design a simple cloud architecture.

## Cloud Infrastructure Components
The main components are compute, storage, networking, and the operating system. These resources work together to support cloud workloads.

## Tools Used
- KillerCoda Playground
- Linux Terminal
- GitHub
- Markdown
- Cloud provider documentation
- Diagramming tool
