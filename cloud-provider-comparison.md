# Cloud Provider Comparison

| Infrastructure | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Compute | EC2 | Virtual Machines | Compute Engine |
| Storage | S3 | Blob Storage | Cloud Storage |
| Networking | VPC | Virtual Network | VPC |
| IAM | AWS IAM | Entra ID / RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers a very broad range of cloud services covering compute, storage, networking, databases, security, and many other areas.

### 2. Which platform is recommended for organizations using Microsoft products?
Microsoft Azure is a strong choice because it integrates closely with Microsoft's products and services.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes?
Google Cloud is widely recognized for its AI and machine learning capabilities and its Kubernetes services.

### 4. What similarities did you observe?
All three providers offer similar core infrastructure services, including compute, storage, networking, and identity management. Their service names and implementations differ, but their basic purposes are similar.
